🚀 Supply Chain Sales Analytics Dashboard | Power BI

An end-to-end data analytics project that transforms raw supply chain data into actionable business insights using Power BI.

🧠 Project Overview

This project focuses on analyzing supply chain sales performance by cleaning, modeling, and visualizing data to support data-driven decision making.

🔎 Key Steps
Data cleaning and preprocessing (CSV files)
Data modeling using relational structure
Building interactive Power BI dashboard
KPI calculation and business insights extraction
Data visualization for decision support
📊 Key KPIs
Total Sales
Total Profit
Profit Margin
Total Quantity Sold
📈 Dashboard Insights
Identified top-performing products
Sales trends across regions and time
Profitability analysis by category
Customer and segment performance
🛠️ Tools & Technologies
Power BI
Excel
Data Modeling
Data Visualization
Business Intelligence
📁 Project Structure
data/ → Raw datasets
images/ → Dashboard screenshots

🚀 Objective

To demonstrate end-to-end BI workflow from raw data to interactive dashboard and actionable insights.
