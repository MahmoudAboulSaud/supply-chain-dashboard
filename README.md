🚀 End-to-End Supply Chain Analytics Dashboard | Power BI Project

An end-to-end data analytics project that transforms raw supply chain data into actionable business insights using Power BI.

🧠 Project Overview

This project focuses on analyzing supply chain sales performance by cleaning, modeling, and visualizing data to support data-driven decision making.

The goal is to simulate a real business analytics scenario where raw transactional data is converted into meaningful KPIs and interactive dashboards.

🎯 Business Problem

Organizations need to analyze supply chain performance to:

Identify sales trends over time
Improve profitability across products and categories
Understand customer and regional performance
Optimize decision-making using data insights
🔎 Project Workflow
Data extraction from multiple CSV datasets
Data cleaning and preprocessing using Power Query
Building relational data model (Star Schema)
Creating calculated measures using DAX
Designing interactive Power BI dashboard
Generating business insights from visual analytics
📊 Key KPIs
Total Sales
Total Profit
Profit Margin
Total Quantity Sold
📈 Key Insights
Identified top-performing and low-performing products
Sales distribution across regions and time periods
Profitability analysis by category and segment
Customer behavior and purchasing trends
📌 Business Impact
Improved visibility of supply chain performance
Enabled faster and smarter decision-making
Highlighted key revenue drivers and inefficiencies
Supported strategic planning through data insights
🛠️ Tools & Technologies

Power BI | DAX | Power Query | Excel | Data Modeling | Data Visualization | Business Intelligence
